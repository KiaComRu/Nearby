# Nearby

Передача файлов между компьютерами и телефонами по локальной сети или через интернет. Разработчик: **Dev.KiaCom / KiaComRu**.

**Версия 0.5.8 для Windows 10/11 x64:** собственное окно приложения, встроенный Node.js и подключение телефона через браузер по QR-коду и PIN. Отдельные приложения Android, iOS и macOS пока не выпущены.

В этом репозитории находятся исходники приложения, тесты, документация и скрипты сборки. Лендинг и установщик EXE хранятся отдельно. Лендинг и скачивание Windows-установщика: https://nearby.kiacom.ru.

**Браузерная версия (бета): https://nearby.kiacom.ru/web/** — автоматически выбирает прямой WebRTC или зашифрованный HTTPS-канал. Подключение по девятизначному ID, QR или ссылке; несколько устройств и таблицы передач. В Windows кнопка «Открыть веб-версию» запускает её в системном браузере. Оба устройства должны иметь доступ к сайту; держите вкладки открытыми. [Инструкция и разработка](docs/BROWSER-MODE.md).

## Возможности

Веб-версию можно установить на главный экран телефона как **PWA**. Android: меню браузера → «Установить приложение»; iPhone: Safari → «Поделиться» → «На экран “Домой”». [Установка, офлайн-экран и ограничения](docs/PWA.md).

В ПК-интерфейсе блок «Компьютеры рядом» показывает карточки найденных устройств: векторная иконка, имя, IP и кнопка «Подключиться». Для нового защищённого ПК она запускает сверку на двух экранах, для сохранённого — подключение без PIN. Телефон можно пригласить по QR-коду, а ПК вне списка — подключить по адресу. Для разных сетей нажмите «Открыть веб-версию»: веб-версия автоматически выберет доступный транспорт.

«Отдать файлы», «Входящие запросы» и «Передачи» появляются только после установления связи. Найденный или сохранённый ПК сам по себе их не открывает. При явном отключении отправка недоступна до выбора нового получателя; история остаётся доступной; при закрытии вкладки или потере связи входящее подключение исчезает после 45 секунд без активности.

- Телефон → компьютер: выбор файлов в браузере и автоматический приём в Nearby.
- Компьютер → телефон: отправка выбранному получателю и автоматическая загрузка в браузере.
- QR-код и шестизначный PIN для подключения в локальной сети.
- Прогресс отправки и сохранение полученных файлов.
- Windows-приложение сохраняет файлы в системную папку «Загрузки → Nearby», отдельно от установки программы.

## Запуск из исходников

Нужен Node.js 22 или новее.

```sh
npm ci
npm start
```

На Windows можно запустить `start-windows.cmd`: он установит зависимости при первом запуске. В консоли появятся адрес окна владельца и ссылки для подключения. Окно владельца открывайте на компьютере, где запущен сервер; телефон подключайте к той же доступной локальной сети.

В браузерном режиме полученные файлы сохраняются в `storage/received`, копии раздачи — в `storage/shared`. В установленном Windows-приложении используются отдельные пользовательские папки. QR заполняет PIN автоматически; подключение подтверждается в интерфейсе. Не передавайте ссылку окна владельца другим пользователям.

## Сборка Windows-установщика

На Windows x64 с Node.js 22+, .NET Framework 4.8 и PowerShell:

```sh
npm ci
npm test
npm run build:windows
```

Результат: `artifacts/Nearby-0.5.8-windows-x64-setup.exe` и метаданные с SHA-256. Скрипт загружает инструменты в `.build-tools`; пользователю готового установщика Node.js и средства разработки не нужны. Для работы окна требуется WebView2 Runtime. Подробности: [установка и сборка Windows](docs/INSTALL-WINDOWS.md).

Текущий установщик не подписан. Полный цикл установки и удаления на чистой Windows и работа с физическими мобильными устройствами требуют отдельной проверки.

Для Windows Server 2016 x64 с Desktop Experience есть отдельный профиль .NET Framework 4.6.2: `npm run build:server2016`. [Установка и ограничения серверной сборки](docs/WINDOWS-SERVER-2016.md).

## Ограничения

Локальный режим по PIN использует **HTTP без шифрования**. Защищённое сопряжение двух ПК в 0.5.0 использует взаимный TLS 1.3 и сохранённые ключи; см. [инструкцию](docs/TRUSTED-DEVICES.md). Работайте только в доверенной локальной сети; не публикуйте сервер приложения в интернете и не пробрасывайте его порт. PIN и токены не защищают от перехвата сетевого трафика. HTTPS лендинга относится к сайту, а не к локальному транспорту.

Оставляйте Nearby открытым до завершения передачи. Фоновой передачи, возобновления после обрыва и выбора папок пока нет. Все подключённые по PIN устройства видят общую раздачу. macOS Catalina не поддерживает сервер на Node.js 22+; отдельная версия для неё пока только запланирована.

Реализованные ограничения: до 100 ГиБ на файл и до трёх одновременных записей; размеры такого порядка в реальной сети не проверялись. Практические ограничения зависят также от браузера, диска и сети.

## Проверки

```sh
npm test
node --check public/app.js
node --check desktop/windows/host.mjs
```

Тесты используют временные каталоги и loopback-соединения. Проверяются согласие на приём, принадлежность запроса, точность двоичных данных, одноразовое скачивание, обрыв загрузки, PIN и сетевые ограничения. CI запускает их на Windows; проверка содержимого Windows-дистрибутива пропускается до его сборки. Результаты и пределы проверки: [docs/VALIDATION.md](docs/VALIDATION.md).

## Общий счётчик Nearby

Windows 0.3.0, локальный запуск из исходников и браузерная версия пополняют общий итог файлов и байтов. Счётчик виден в интерфейсах и на лендинге. Передаются только размер, случайный ID, время и тип клиента; имена, пути и содержимое файлов в статистику не входят. Без интернета Windows сохраняет до 1000 отчётов не старше 7 дней и отправляет их при следующем запуске. Локальная передача работает независимо от счётчика. Старым установленным версиям нужно вручную установить 0.3.0. Подробнее: [учёт и хранение](docs/STATISTICS.md).
## ПК ↔ ПК в Windows 0.3.0

Nearby теперь подключает два установленных Windows-приложения в одной локальной сети. На первом ПК скопируйте ссылку в режиме «Пригласить устройство», на втором выберите «Подключиться к ПК», вставьте ссылку и подтвердите PIN. Входящие файлы принимаются на первом ПК, файлы из его раздачи скачиваются на второй. Понадобится обновить оба приложения. [Пошаговая инструкция и ограничения](docs/PC-TO-PC.md). Проверка интерфейса: npm run test:pc.
## Устройства рядом — 0.4.0

В общей IPv4-сети Nearby находит другие открытые приложения. Выберите ПК из списка, проверьте ответ и введите PIN с его экрана. При нескольких адаптерах выберите адрес общей сети. Кнопка «Проверить адрес» различает отказ порта, тайм-аут, отсутствие маршрута и несовместимое приложение; настройки брандмауэра автоматически не меняются. Ручной адрес/PIN и интернет-режим сохраняются. Обновите оба ПК. [Инструкция](docs/DISCOVERY.md). [Порядок дальнейших этапов](docs/ROADMAP.md).

## Защищённое сопряжение — 0.5.0

В «Устройствах рядом» нажмите «Сопрячь устройства», сверяйте всю строку из 8 групп на двух ПК и подтвердите на обоих. Затем используйте «Подключиться защищённо» в «Моих устройствах»: взаимный TLS 1.3, проверка точного ключа и повторное подключение без PIN. Доступны локальное переименование и отзыв доверия с остановкой незавершённой передачи. Ключ Windows защищён DPAPI, хранится вне установки и сохраняется при обновлении. Телефонный QR/PIN остаётся отдельным HTTP-режимом; браузерный интернет-транспорт не менялся. [Подробности](docs/TRUSTED-DEVICES.md).

## Отправка из Проводника — 0.5.4

Пункт «Отправить через Nearby» добавляет выбранные файлы в уже открытое приложение и предлагает активного получателя. Файлы доступны только выбранному устройству. Поддерживаются Windows 10/11 и Server 2016 с рабочим столом. [Как пользоваться](docs/CONTEXT-MENU.md).

## Компактный интерфейс — 0.5.4

Две вкладки: «Подключение» и «Передача». Устройства подтверждаются один раз, после чего файлы принимаются автоматически. Статистика видна под вкладками. В Windows файлы сохраняются в Nearby без отдельного диалога; в браузере можно один раз выбрать папку. [Интерфейс и ограничения браузера](docs/INTERFACE.md).

## Обновления Windows — 0.5.4

Новая версия проверяется при запуске и каждые шесть часов. Уведомление предлагает обновиться или отложить. Установка ждёт завершения передач, проверяет SHA-256, сохраняет данные и автоматически запускает Nearby. Для 0.5.3 требуется один раз поставить 0.5.4 поверх прежней версии. [Подробности и проверки](docs/UPDATES.md).

Веб/PWA и оба профиля Windows показывают миниатюры изображений слева от имени файла. Столбец статуса содержит только ⓘ; наведение и нажатие открывают текстовую подсказку. [Форматы, ограничения и проверки](docs/PREVIEWS-0.5.8.md).
