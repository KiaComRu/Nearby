# Nearby

Передача файлов между компьютером и телефоном в одной локальной сети. Разработчик: **Dev.KiaCom / KiaComRu**.

**Версия 0.2.0 для Windows 10/11 x64:** собственное окно приложения, встроенный Node.js и подключение телефона через браузер по QR-коду и PIN. Отдельные приложения Android, iOS и macOS пока не выпущены.

В этом репозитории находятся исходники приложения, тесты, документация и скрипты сборки. Лендинг и установщик EXE хранятся отдельно. Лендинг и скачивание Windows-установщика: https://nearby.kiacom.ru.

**Браузерная версия (бета): https://nearby.kiacom.ru/web/** — прямой обмен через WebRTC между двумя браузерами без установки. QR-приглашение, подтверждение устройства, согласие на приём, прогресс и отмена. Для старта нужны интернет и одна доступная локальная сеть; вкладки должны оставаться открытыми. Сохранение и пределы размера зависят от браузера. [Инструкция и разработка](docs/BROWSER-MODE.md).

## Возможности

- Телефон → компьютер: выбор файлов в браузере и подтверждение приёма в Nearby.
- Компьютер → телефон: добавление файлов в раздачу и скачивание в браузере.
- QR-код и шестизначный PIN для подключения в локальной сети.
- Прогресс отправки и сохранение полученных файлов.
- Windows-приложение сохраняет файлы в системную папку «Загрузки → Nearby», отдельно от установки программы.

## Запуск из исходников

Нужен Node.js 22 или новее.

```sh
npm ci
npm start
```

На Windows можно запустить `start-windows.cmd`: он установит зависимости при первом запуске. В консоли появятся адрес окна владельца и ссылки для подключения. Окно владельца открывайте на компьютере, где запущен сервер; телефон подключайте к той же доступной локальной сети.

В браузерном режиме полученные файлы сохраняются в `storage/received`, копии раздачи — в `storage/shared`. В установленном Windows-приложении используются отдельные пользовательские папки. QR заполняет PIN автоматически; подключение подтверждается в интерфейсе. Не передавайте ссылку окна владельца другим пользователям.

## Сборка Windows-установщика

На Windows x64 с Node.js 22+, .NET Framework 4.8 и PowerShell:

```sh
npm ci
npm test
npm run build:windows
```

Результат: `artifacts/Nearby-0.2.0-windows-x64-setup.exe` и метаданные с SHA-256. Скрипт загружает инструменты в `.build-tools`; пользователю готового установщика Node.js и средства разработки не нужны. Для работы окна требуется WebView2 Runtime. Подробности: [установка и сборка Windows](docs/INSTALL-WINDOWS.md).

Текущий установщик не подписан. Полный цикл установки и удаления на чистой Windows и работа с физическими мобильными устройствами требуют отдельной проверки.

## Ограничения

Передача использует **HTTP без шифрования**. Работайте только в доверенной локальной сети; не публикуйте сервер приложения в интернете и не пробрасывайте его порт. PIN и токены не защищают от перехвата сетевого трафика. HTTPS лендинга относится к сайту, а не к локальному транспорту.

Оставляйте Nearby открытым до завершения передачи. Автопоиска устройств, фоновой передачи, возобновления после обрыва, выбора папок и прямого обмена телефон → телефон пока нет. Все подключённые по PIN устройства видят общую раздачу. macOS Catalina не поддерживает сервер на Node.js 22+; отдельная версия для неё пока только запланирована.

Реализованные ограничения: до 100 ГиБ на файл и до трёх одновременных записей; размеры такого порядка в реальной сети не проверялись. Практические ограничения зависят также от браузера, диска и сети.

## Проверки

```sh
npm test
node --check public/app.js
node --check desktop/windows/host.mjs
```

Тесты используют временные каталоги и loopback-соединения. Проверяются согласие на приём, принадлежность запроса, точность двоичных данных, одноразовое скачивание, обрыв загрузки, PIN и сетевые ограничения. CI запускает их на Windows; проверка содержимого Windows-дистрибутива пропускается до его сборки. Результаты и пределы проверки: [docs/VALIDATION.md](docs/VALIDATION.md).

## Устройство проекта

| Каталог/файл | Назначение |
| --- | --- |
| `server.mjs` | HTTP API, PIN, приём и раздача файлов |
| `public/` | Браузерный интерфейс |
| `browser/` | Самостоятельный браузерный режим WebRTC и PHP-сигналинг |
| `desktop/windows/` | Windows-оболочка и сборка установщика |
| `test/` | Интеграционные тесты |
| `docs/` | Установка, протокол, архитектура и проверки |
