如何免费从手机发送文件

在两台设备上打开 Nearby，创建邀请，并通过二维码、链接或九位数字 ID 连接。确认设备后，在手机上选择文件。接收会自动开始；关闭页面前请保存已接收文件。

免费传文件的四个步骤

  1. 在手机和接收设备上打开此页面。
  2. 创建邀请，在另一台设备上打开链接或扫描二维码，也可以输入完整的九位 ID。
  3. 在创建邀请的设备上确认连接，然后在手机上选择接收方和文件。
  4. 等待接收完成，从列表中打开或保存文件。在 iPhone 和 iPad 上，点按打开文件图标。

免费文件传输常见问题

如何免费从手机传文件到另一部手机？

在两部手机的浏览器中打开 Nearby，创建邀请，并通过二维码、链接或 ID 连接第二部手机。确认设备并选择文件。支持 Android 和 iPhone，可在不同 Wi-Fi 或移动网络间使用，无需安装应用或注册。

如何免费从手机传文件到 PC？

在手机和 Windows PC 上打开此页面。在 PC 上创建邀请，用手机相机扫描二维码或输入 ID。在 PC 上确认连接，再从手机选择并发送文件，无需数据线或安装软件。

如何免费从手机传文件到电脑？

Nearby 可在 Windows、macOS 和 Linux 的浏览器中使用。在电脑和手机上打开 Nearby，通过邀请连接后发送文件。传输免费，无需 USB 数据线或账号。

如何免费从手机传文件到平板？

在手机及 Android 平板或 iPad 上打开 Nearby，创建邀请并连接另一台设备。在手机上选择文件。在 iPad 上，从列表打开收到的文件，再用 Safari 的分享菜单保存。传输期间请保持两个页面打开。

Nearby 真的免费吗？

是的。Nearby 网页应用免费使用，无需注册、订阅或支付传输费用。连接时两台设备都需要联网。Nearby 会优先使用直连，不可用时改用加密互联网通道。

可以免费传多大的文件？

手机浏览器的普通接收和互联网通道支持每个文件最多 100 MiB。接收端为 PC 上的 Chrome 或 Edge，并提前选择接收文件夹时，直连可支持最多 10 GiB。发送前会显示接收方的实际限制。

不同网络之间也能免费传文件吗？

可以。Nearby 自动检查直连，必要时切换到端到端加密的互联网通道。请在两台设备上保持 Nearby 打开，不要锁定手机，并在关闭页面前保存收到的文件。
