# Nearby 0.5.9 — общий столбец иконок

В таблицах отправленных и полученных файлов остаются четыре столбца: название с превью, размер, дата/время и пустой заголовок. В последнем столбце стоят рядом три значка: ⓘ для статуса, окно со стрелкой ↗ для открытия файла и × для удаления записи из списка. Видимых подписей «Статус», «Действия» и «Открыть» больше нет.

Для открытия выбран привычный знак launch/open in new: контур окна со стрелкой наружу. В веб-версии он открывает поддерживаемый файл в новой вкладке; прочие форматы сохраняются через браузер. Windows открывает оригинал или принятый файл обычным приложением. [Использование launch icon в Carbon Design System](https://carbondesignsystem.com/components/button/usage/).

У значков сохранены доступные названия. Подсказки «Открыть» и «Удалить из списка» переведены на пять языков веб-интерфейса. ⓘ показывает текущий текст статуса при наведении, фокусе и нажатии. Иконки сохраняют положение при обновлении прогресса. Открытие недоступного или ещё передающегося файла отключено; во время веб-передачи × отменяет её, после завершения — удаляет запись, сохраняя файл.

Изменения включены в веб/PWA, Windows 10/11 и Windows Server 2016 с Desktop Experience. Метрика, маскирование приватных данных, превью и выбор получателя сохраняются.
