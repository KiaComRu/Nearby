# Nearby для Windows 0.6.5 — одно приглашение для любой сети

На вкладке «Подключение» нажмите **«Пригласить устройство»**. Nearby создаёт один QR-код, ссылку HTTPS и девятизначный ID. Откройте QR камерой телефона либо введите ID в Nearby на другом ПК. На приглашающем устройстве подтвердите подключение.

Выбирать локальную сеть или интернет заранее не требуется. По умолчанию Nearby проверяет прямой канал WebRTC между устройствами; если он недоступен, согласует зашифрованный интернет-канал. При потере прямой связи приложение может перейти на интернет в рамках того же сопряжения, без нового QR. Если файл был прерван при переключении, отправьте его заново после восстановления связи.

В списке устройств показан фактический канал: **«WebRTC · напрямую»** или **«Интернет · сквозное шифрование»**. Поиск соседних ПК и сохранённые TLS-сопряжения остаются доступны. Отправка из Проводника использует того же выбранного получателя и канал.

## Подключение без доступа к сайту

Для создания и согласования единого HTTPS-приглашения оба устройства должны иметь доступ к сайту Nearby. Даже в общей сети это не автономный режим. Если интернет недоступен, откройте шестерёнку → «Способ подключения» → **«Локальная сеть без интернета — адрес и PIN»**. Локальный QR работает только в доступной сети этого ПК. Поиск и защищённое сопряжение соседних ПК также используют локальную сеть.

В дополнительных настройках есть и принудительный интернет-режим для диагностики. Параметр применяется к новым приглашениям; уже созданное приглашение сохраняет свой режим. В штатном автоматическом режиме на основном экране показывается один QR.

## Ограничения и обновление

Единое приглашение действует 15 минут и используется один раз. Передача через этот сеанс ограничена **100 МиБ на файл**, в том числе при выборе прямого WebRTC-канала. Полученные на Windows файлы сохраняются в «Загрузки → Nearby». На iPhone/iPad файл появляется в «Принятых файлах», открытие и сохранение — по иконке окна со стрелкой. Оставляйте Nearby открытым до завершения передачи.

Установите Windows 0.6.5 поверх прежней версии: отдельно доступны Windows 10/11 x64 и Windows Server 2016 x64 с Desktop Experience. Существующие установки 0.5.4 и новее получают предложение обновления через свой канал. Веб/PWA сохраняет исправление iPhone из версии 0.6.4 и принимает автоматическое приглашение без дополнительной установки.

## Проверки

- `desktop-auto-e2e.mjs`: ПК → телефон и ПК → ПК напрямую и через интернет, один HTTPS-QR и короткий ID, SHA-256 в обе стороны, пустые файлы, потеря прямого канала с переходом на интернет без нового сопряжения, доступность локального режима.
- `desktop-internet-e2e.mjs --native`: настоящее окно WinForms/WebView2, автоматическое приглашение, обмен с другим ПК и телефоном, Проводник, запись на диск, открытие файлов и SHA-256.
- `compact-ui-e2e.mjs`, `discovery-e2e.mjs`, `trusted-e2e.mjs`: компоновка, независимый локальный режим, обнаружение соседей, TLS-сопряжение и сохранённые устройства.

Проверки выполнены на одном Windows-компьютере с изолированными движками и браузерными контекстами. Недоступность прямой связи моделируется отключением WebRTC у получателя. Физический iPhone, разные маршрутизаторы и Windows Server 2016 отдельно не проверялись.
