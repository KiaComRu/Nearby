# Nearby в браузере — бета

Адрес: https://nearby.kiacom.ru/web/. Установка приложения на компьютер или телефон не требуется.

1. Подключите оба устройства к одной доступной локальной сети. Для загрузки сайта и установления связи нужен интернет.
2. На первом устройстве нажмите «Создать подключение».
3. На втором устройстве откройте QR-код камерой или вставьте ссылку-приглашение. Нажмите «Подключиться».
4. На первом устройстве подтвердите, что подключается ваш получатель.
5. Выберите файлы на любом из устройств. Получатель подтверждает каждый файл.

Приглашение одноразовое, действует 15 минут и содержит случайный секрет в URL-фрагменте. Фрагмент очищается из адресной строки при открытии. Не публикуйте приглашения. В комнате только два устройства; переподключение после закрытия требует нового приглашения.

Имя устройства заполняется автоматически, например «iPhone · Эльбрус» или «Windows · Дыхтау»: используются названия высоких вершин России. Его можно изменить перед подключением. Имя сохраняется в localStorage этого браузера; если хранилище недоступно, подключение всё равно работает. Ранее сохранённые стандартные имена с «Луной», «Клёном» и другими названиями первой версии заменяются один раз; остальные сохранённые имена остаются. В приватном режиме имя может не сохраниться после закрытия окна. Системное имя пользователя или компьютера, а также имя профиля браузера сайту недоступны; тип устройства определяется приблизительно по сведениям браузера.

## Передача и сохранение

WebRTC DataChannel передаёт файлы напрямую с транспортным шифрованием DTLS. PHP на хостинге обменивает только описания соединения и ICE-кандидаты. Файлы не загружаются на Sweb. Сервер соединения доверенный: HTTPS и секрет приглашения не защищают от компрометации самого сайта.

Используются упорядоченные сообщения, части по 16 КиБ, SHA-256 каждой части и подтверждение после записи. Приём начинается только после согласия. Одновременно можно передавать по одному файлу в каждом направлении; выбранные файлы отправляются последовательно. При отмене или разрыве докачки нет. Проверка частей обнаруживает повреждение передачи; это не независимая подпись всего файла.

На Windows в поддерживающих File System Access API Chrome/Edge можно выбрать файл назначения и записывать части без хранения всего файла в памяти. Программный предел — 10 ГиБ на файл; проверка фактической передачи такого объёма и разных файловых систем ещё нужна.

В браузерах без `showSaveFilePicker`, включая Safari на iPhone, используется буферизация и кнопка «Сохранить файл» после приёма. Предел — 100 МиБ на файл и суммарно на удерживаемые вкладкой файлы. Память и поведение сохранения зависят от браузера и устройства. Сохраняйте полученное и удаляйте его из памяти вкладки перед следующими крупными файлами. Не закрывайте вкладки и не блокируйте телефон до завершения.

В версии бета нет STUN/TURN и серверной пересылки файлов. Сеть с изоляцией клиентов, VPN, некоторые сочетания браузеров или настройки локального доступа могут не разрешать прямое соединение. Разрешите доступ к локальной сети, если браузер его запрашивает. Между разными сетями соединение не гарантируется. Windows-приложение 0.2.0 использует другой HTTP-протокол: браузерный режим подключается к другому браузерному режиму.

## Разработка

Нужны Node.js 22+ и PHP 8.1+ (на Sweb проверена CLI-версия 8.3).

```sh
npm ci
npm run build:web
php -S 127.0.0.1:8088 -t browser
```

Откройте http://127.0.0.1:8088/ для локальной разработки. Для телефонов нужен публичный HTTPS. Локальный `php -S` предназначен для разработки, а не для публичного сервера.

```sh
npm run test:web
npx playwright install chromium
npm run test:browser
```

Тесты PHP запускаются, когда `php` доступен в PATH или переменная `PHP_PATH` содержит путь к исполняемому файлу. `NEARBY_WEB_URL` меняет адрес браузерных проверок. CI проверяет PHP 8.3 и Chromium. Два изолированных контекста на одном компьютере не заменяют тест на физических Windows/iPhone/Android и разных роутерах.

## Развёртывание на PHP-хостинге

После `npm run build:web` загрузите `index.html`, `styles.css`, `app.js`, `transfer.mjs`, `api.php`, `.htaccess` и `vendor/` в публичную папку `/web/`. Сборщик и node_modules на хостинге не нужны. Сохраните MIT-уведомление QR-библиотеки. Apache должен отдавать `.mjs` как JavaScript.

Данные подключения храните **вне публичного каталога**, в отдельной папке с правами 0700. Укажите её через переменную `NEARBY_WEB_STATE_DIR` либо файл `config.private.php`, возвращающий массив с `stateDirectory`. Конфигурацию исключайте из Git; прямой доступ к ней запрещён `.htaccess`. Без настройки используется отдельная папка в системном temp. API ограничивает размер JSON, количество комнат/запросов и срок подключения, применяет блокировки файлов и не принимает пользовательские файлы. Истёкшие комнаты очищаются при создании новых; для очистки в периоды простоя можно добавить отдельное задание планировщика.

Публикация нового транспорта не меняет существующий Windows-установщик.
