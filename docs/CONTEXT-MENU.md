# Отправка из Проводника Windows

Доступна с Nearby 0.5.2 в обычной сборке Windows 10/11 x64.

## Как отправить файл

1. Установите 0.5.2. Установщик добавляет пункт **«Отправить через Nearby»** в контекстное меню файлов и ярлык **«Отправить → Nearby»**.
2. Выделите один или несколько файлов в Проводнике. В Windows 11 при необходимости откройте **«Показать дополнительные параметры»** или нажмите Shift+F10.
3. Нажмите **«Отправить через Nearby»**, выберите подключённое устройство и нажмите **«Отправить»** в Nearby.
4. При отправке на ПК, к которому Nearby подключён как клиент, получатель подтверждает каждый файл. При отправке устройству, подключившемуся к этому ПК, файл становится доступен для скачивания только этому устройству. Получатель нажимает «Скачать»; до этого файл ещё не считается переданным.

Если Nearby уже открыт, команда добавляет файлы в его текущее окно и сохраняет соединение. При закрытом приложении Nearby запускается. Если подключений ещё нет, закройте выбор получателя, подключите устройство и нажмите **«Файлы из Проводника»**. Выбор сохраняется, пока приложение открыто. Повторные команды добавляют файлы к выбору. Само открытие меню не увеличивает счётчик использований.

## Ограничения

- До 100 файлов в одном выборе. Для нескольких файлов также доступно «Отправить → Nearby».
- Папки нужно предварительно упаковать в ZIP. Исходные файлы не перемещаются и не удаляются.
- Показаны активные локальные подключения этого Windows-приложения, а не просто найденные или когда-то сохранённые устройства. При пропадании клиента список обновляется по его активности; без штатного отключения это может занять до 45 секунд.
- Если соединение изменилось, отправка останавливается; новый получатель автоматически не подставляется. Файлы не рассылаются всем устройствам.
- Интернет-подключения веб-версии существуют в отдельном браузере и в этот список не входят. Для них используйте выбор файлов в веб-версии.
- Остановка во время ожидания подтверждения прекращает отправку; уже показанный на другом ПК запрос может оставаться до истечения пяти минут. Повторная отправка создаёт новый запрос.
- В Windows 11 используется классическое меню. Регистрация в новом основном меню Windows 11 остаётся отдельной возможностью.

## Установка и данные

Команда регистрируется только для текущего пользователя в `HKCU\Software\Classes\*\shell\Nearby.Send`, без прав администратора. Удаление Nearby убирает команду и ярлык SendTo. Системные настройки меню Windows не меняются. Файлы обновления сохраняют прежние полученные файлы, сопряжения и статистику.

Между повторными запусками EXE передаются только выбранные пути, через именованный канал с доступом текущего пользователя Windows. Пути не помещаются в сетевой URL, журнал или файл активации. WebView2 получает выбранные файлы через файловый ввод; получателю доступны имя, размер и содержимое выбранного файла, но не исходный путь.

Проверки: `npm run test:shell` проверяет выбор получателей, сохранение выбора до подключения, приватность раздачи, бинарные/пустые файлы и отказ. `npm run test:shell:native` после сборки Windows проверяет настоящее WinForms/WebView2-окно, приватный IPC и повторные активации EXE с сохранением соединения. Тесты используют временные данные с отключённой статистикой.
