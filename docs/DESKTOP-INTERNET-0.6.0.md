# Nearby 0.6.0 — интернет в приложении Windows

Выпуск для Windows 10/11 x64 и Windows Server 2016 с рабочим столом позволяет соединять устройства из разных сетей прямо в приложении. Внешний браузер на ПК для этого не требуется. На телефоне работает прежняя веб/PWA-версия Nearby.

## Подключение

1. Обновите приложения на обоих ПК до 0.6.0. Для телефона достаточно открыть веб-версию Nearby.
2. На вкладке «Подключение» откройте «Дополнительные настройки» и выберите «Интернет».
3. Нажмите «Пригласить». Приложение покажет девятизначный ID, QR-код и ссылку. Приглашение действует 15 минут и используется один раз.
4. На другом ПК также выберите «Интернет», введите ID или полную ссылку и нажмите «Подключиться». На телефоне отсканируйте QR-код или откройте ссылку.
5. На приглашающем устройстве проверьте имя получателя и разрешите подключение.
6. Выберите файлы на вкладке «Передача». Если подключено несколько устройств, сначала выберите получателя на вкладке «Устройства».

Можно принимать приглашения из веб-версии: вставьте её ID или полную ссылку в поле интернет-подключения Windows. Поддерживаются автоматический и интернет-режим веб-приглашения. Локальный шестизначный PIN Windows используется отдельно, в общей сети.

## Передача и получение

- Интернет-устройства входят в общий список вместе с локальными. Они доступны и при отправке через пункт Nearby в Проводнике.
- Полученные файлы автоматически сохраняются в настроенную папку Nearby, по умолчанию «Загрузки → Nearby». Успешная передача подтверждается после сохранения файла.
- Таблица, превью и иконки статуса, открытия и удаления остаются общими. Удаление записи из таблицы сохраняет файл на диске.
- При отключении получателя приложение не переключает незавершённую очередь на другое устройство.

## Ограничения и защита

На текущем хостинге действует предел **100 МиБ на файл через интернет**. Оба устройства должны оставаться онлайн, приложение и вкладка телефона — открытыми. После обрыва незавершённый файл нужно отправить заново. Локальные подключения сохраняют прежние лимиты.

Имена файлов, содержимое и служебные сообщения передачи шифруются на устройствах AES-256-GCM. Используется тот же совместимый протокол, что в веб-версии. Короткий ID ищет одноразовое приглашение; ключ шифрования согласуется отдельно через ECDH. Полная ссылка содержит секрет во фрагменте после `#`; передавайте её только ожидаемому получателю.

Приложение обращается к существующему HTTPS-сервису Nearby через собственный локальный движок. Адрес сервиса фиксирован; локальный токен владельца не отправляется в интернет. Открывать порты роутера, покупать VPS или настраивать TURN не требуется. Яндекс Метрика в локальное окно Windows не добавляется.

## Проверка выпуска

Автоматический тест изолирует браузеры двух ПК друг от друга, отключает WebRTC и разрешает только обращения к их собственным локальным движкам. Передача проходит через отдельный тестовый PHP-сервис; проверяются двусторонняя передача, SHA-256, пустой файл, телефон, выбор получателя, Проводник и точный общий счётчик. Отдельно проверяются права владельца, ограничения размера, целостность сохранения и блокировка обновления во время приёма.

Автоматические проверки не заменяют испытания на двух физических компьютерах в сетях разных провайдеров. Корпоративный прокси или блокировка сайта Nearby могут ограничить доступ к интернет-сервису.
