# Установка Nearby на Windows

Версия 0.2.0, Windows 10/11 x64. Это первая устанавливаемая Windows-версия текущего прототипа. Она использует собственное окно на WinForms/WebView2 и встроенный Node.js. Пользователю не нужны Node.js, npm, консоль или папка с исходниками.

## Установка и запуск

1. Запустите `artifacts/Nearby-0.2.0-windows-x64-setup.exe`.
2. Программа устанавливается для текущего пользователя в `%LOCALAPPDATA%\Programs\Nearby`, без запроса прав администратора.
3. Запускайте Nearby через ярлык на рабочем столе или в меню «Пуск».
4. Подключите телефон к той же доступной локальной сети, отсканируйте QR-код и подтвердите подключение по PIN.
5. При входящем запросе нажмите «Принять». Файлы сохраняются в системную папку **«Загрузки → Nearby»**. Полный путь и кнопка «Открыть папку» видны в окне программы.

Системная папка «Загрузки» определяется через Windows Known Folders, поэтому учитывает её перенос. Служебные данные находятся в `%LOCALAPPDATA%\Nearby\Data`; исходные файлы для раздачи не меняются. При обновлении/удалении папка полученных файлов и служебные данные не удаляются. Для удаления самой программы используйте список установленных приложений Windows.

Файлы, ранее полученные браузерным прототипом, остаются в `storage/received` папки проекта. Они не переносятся и не включаются в установщик.

При закрытии окна движок передачи останавливается. Оставляйте приложение открытым до завершения передачи. PIN меняется при каждом запуске. Порт выбирается автоматически, поэтому приложение может работать рядом с браузерным прототипом и не конфликтует с его портом 53317.

## Требуемые системные компоненты

- .NET Framework 4.8.
- Microsoft Edge WebView2 Evergreen Runtime. На проверяемом компьютере он уже установлен. Если компонента нет, Nearby покажет ссылку на [официальную страницу Microsoft](https://developer.microsoft.com/microsoft-edge/webview2/). Автоматическая установка системных компонентов не выполняется.
- Доступ входящих соединений приложения к доверенной частной сети. Программа не изменяет брандмауэр автоматически.

Установщик и оболочка пока **без цифровой подписи**. Это тестовая сборка для проверки, не подписанный публичный выпуск. Система может показывать предупреждение о неизвестном издателе; автоматический обход проверок не выполняется.

Соединение первой версии использует HTTP без шифрования. Работа — только в доверенной локальной сети, без проброса порта в интернет. Нативный транспорт с TLS и сопряжением устройств остаётся отдельным этапом.

## Что делает установщик

Копирует программу, встроенный движок Node.js, WebView2 SDK-библиотеки и production-зависимости QR-кода. Создаёт ярлыки и запись удаления для текущего пользователя. Не содержит `storage`, фотографий, тестовых файлов, логов, исходных сборочных инструментов или персональных токенов. WebView2 Runtime не включён: используется установленный Evergreen Runtime.

Не устанавливает Rust, Visual Studio, Android SDK и другие средства разработки.

## Повторная сборка

На Windows x64 с Node.js 22+, .NET Framework 4.8 и PowerShell:

```powershell
npm ci
npm test
npm run build:windows
```

Результаты:

- `artifacts/Nearby-0.2.0-windows-x64-setup.exe` — установщик.
- `artifacts/windows-build.json` — версии компонентов и SHA-256 установщика.
- `dist/windows-x64/Nearby.exe` — запускаемая сборка до упаковки. Для запуска нужна вся папка `dist/windows-x64`, одного EXE недостаточно.

Скрипт использует системный C#-компилятор .NET Framework, официальный WebView2 SDK из NuGet (с проверкой SHA-512 из метаданных NuGet) и переносимый NSIS из официального зеркала Tauri. Инструменты загружаются в `.build-tools`, системные SDK и глобальные переменные окружения не устанавливаются. Русскоязычные PowerShell/C#/NSIS-исходники сохранены в UTF-8 с BOM для совместимости с системными инструментами Windows.

Не изменяйте содержимое `dist/windows-x64` вручную перед сборкой. При существенной смене состава программы используйте новую пустую staging-папку, чтобы не упаковать устаревшие файлы. Тест состава дистрибутива проверяет отсутствие папки данных прототипа.

## Остальные платформы

Эта сборка предназначена только для Windows x64. APK, IPA и DMG пока не созданы. Следующий общий вариант — Tauri 2 с сетевым ядром на Rust; его нужно отдельно собрать и проверить на Android и macOS 10.15. Нынешний Node.js-движок не переносится в iOS/Android и не обеспечивает серверную совместимость с Catalina. Для macOS/iOS потребуются Mac/Xcode либо настроенная облачная сборка и учётные данные подписи для распространения.
