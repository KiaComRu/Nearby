# Интерфейс Nearby для Windows и веб/PWA 0.5.9

На «Подключении» находятся устройства рядом, подключение по адресу, приглашение и общий счётчик. Дополнительные настройки по умолчанию свёрнуты. Когда подключено несколько устройств, появляется вкладка «Устройства» между «Подключением» и «Передачей»; выбранный там получатель показан над отправкой. Входящие файлы от остальных устройств принимаются независимо от выбора. Потерянный получатель не заменяется автоматически.

На «Передаче» две таблицы по четыре столбца: название с превью и устройством, размер, дата и время, а также столбец без заголовка. В последнем стоят рядом ⓘ (статус), окно со стрелкой ↗ (открыть файл) и × (удалить запись). Видимых подписей у иконок нет; доступны подсказки и названия для экранного диктора. Подсказка статуса открывается наведением, фокусом клавиатуры и нажатием; прогресс расположен под именем. Для поддерживаемых изображений до 8 МиБ создаётся миниатюра, для остальных файлов отображается расширение. Крестик скрывает завершённую запись, сохраняя файл на диске. В Windows «Открыть» использует выбранный оригинал, файл в папке приёма или сохранённую загрузку WebView2; обычный браузер может скачать файл повторно. На телефоне панели идут одна под другой, столбцы прокручиваются горизонтально. Статистика остаётся только на «Подключении».

QR-ссылка локального ПК подключает телефон автоматически, без повторного нажатия. Подтверждение можно вернуть в дополнительных настройках. Локальный PIN имеет шесть цифр; веб-ID — девять, например `123-456-789`. Приглашения используют разные протоколы. Первое TLS-сопряжение двух ПК по-прежнему требует сверки на обоих устройствах.

Windows сохраняет файлы в «Загрузки → Nearby». Исходные файлы, сохранённые сопряжения и загрузки не удаляются при обновлении. Интернет-кнопка открывает актуальную веб-версию с автоматическим выбором прямого или зашифрованного HTTPS-канала. Windows 0.6.0 добавляет интернет-подключения в общий список устройств и в отправку из Проводника. [Инструкция](DESKTOP-INTERNET-0.6.0.md). Веб/PWA остаётся версии 0.5.9.

В 0.6.1 кнопка «Пригласить через интернет» доступна на основном экране и сразу создаёт HTTPS-QR для разных сетей. Локальный QR явно помечен. [Как подключить iPhone из другой сети](INVITATIONS-0.6.1.md).

В Windows 0.6.2 настройки вынесены в модальное окно: шестерёнка справа от вкладок доступна с любого экрана. [Подробности](SETTINGS-0.6.2.md).

Веб/PWA 0.6.2 также открывает настройки шестерёнкой справа от вкладок в модальном окне, с переводами на пять языков.

Веб/PWA 0.6.3 на телефонах использует нижнее меню из четырёх пунктов и отдельные экраны отправки и принятых файлов. [Мобильное меню](MOBILE-NAVIGATION-0.6.3.md).

Веб/PWA 0.6.4 сохраняет принятые на iPhone/iPad файлы в списке без автоматического открытия просмотра: иконка окна со стрелкой открывает файл для сохранения. Это сохраняет страницу Nearby активной для следующей передачи. [Исправление повторной отправки](IPHONE-REPEAT-TRANSFER-0.6.4.md).

В Windows 0.6.5 по умолчанию показано единое приглашение: один HTTPS-QR, ссылка и девятизначный ID. Канал выбирается автоматически; поиск соседних ПК остаётся ниже приглашения. Режим по адресу/PIN без интернета доступен через шестерёнку. [Единый QR](AUTOMATIC-QR-0.6.5.md).

В Windows 0.6.6 сворачивание убирает окно в системный трей без закрытия движка и соединений. Значок возвращает прежнее окно, правое меню содержит открытие, проверку обновления и выход. [Работа в трее](TRAY-0.6.6.md).
