# Интерфейс Nearby для Windows 0.5.7 и веб/PWA 0.5.6

На «Подключении» находятся устройства рядом, подключение по адресу, приглашение и общий счётчик. Дополнительные настройки по умолчанию свёрнуты. Когда подключено несколько устройств, появляется вкладка «Устройства» между «Подключением» и «Передачей»; выбранный там получатель показан над отправкой. Входящие файлы от остальных устройств принимаются независимо от выбора. Потерянный получатель не заменяется автоматически.

На «Передаче» две таблицы: название и устройство, размер, дата и время начала, статус и действия. Крестик скрывает завершённую запись, сохраняя файл на диске. В Windows «Открыть» использует выбранный оригинал, файл в папке приёма или сохранённую загрузку WebView2; обычный браузер может скачать файл повторно. На телефоне панели идут одна под другой, столбцы прокручиваются горизонтально. Статистика остаётся только на «Подключении».

QR-ссылка локального ПК подключает телефон автоматически, без повторного нажатия. Подтверждение можно вернуть в дополнительных настройках. Локальный PIN имеет шесть цифр; веб-ID — девять, например `123-456-789`. Приглашения используют разные протоколы. Первое TLS-сопряжение двух ПК по-прежнему требует сверки на обоих устройствах.

Windows сохраняет файлы в «Загрузки → Nearby». Исходные файлы, сохранённые сопряжения и загрузки не удаляются при обновлении. Интернет-кнопка открывает актуальную веб-версию с автоматическим выбором прямого или зашифрованного HTTPS-канала.
