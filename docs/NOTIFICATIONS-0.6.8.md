# Nearby для Windows 0.6.8 — уведомления о полученных файлах

Когда Nearby свёрнут в системный трей, после успешного сохранения входящего файла появляется уведомление Windows «Получен файл» с его именем. Нажатие возвращает окно и открывает список файлов на вкладке «Передача», даже если отправитель уже отключился. Сам файл автоматически не открывается.

В настройках по шестерёнке доступен переключатель **«Уведомлять о полученных файлах в трее»**. По умолчанию он включён. Выбор сохраняется между запусками приложения, включая обновление. Настройка относится к уведомлениям о файлах; уведомления о новых версиях работают как прежде.

Уведомления не появляются, когда окно открыто, при отправке с этого ПК, при ошибке или отмене приёма. Повторное обновление списка не создаёт дубликат. Поддерживаются локальное соединение, защищённое сопряжение ПК, прямой WebRTC и зашифрованный интернет-канал. Получение файла от другого ПК через загрузку WebView2 также вызывает уведомление после завершения записи.

Событие сохранения поступает из встроенного движка по частному каналу Windows-оболочке; для завершившейся загрузки используется событие WebView2. Оба пути проверяют состояние трея и настройку. Русские имена передаются в UTF-8. Настройка хранится в `%LOCALAPPDATA%\Nearby\Data\desktop-settings.json` вне папки установки.

Проверки: `node scripts/receive-notifications-native-e2e.mjs`, `node scripts/tray-native-e2e.mjs`, `node scripts/update-native-e2e.mjs`, `npm test`. Используются настоящее окно WinForms/WebView2 и изолированные файлы, подключения и параметры. Тест перехватывает вызов системного уведомления; фактический показ Windows зависит от системных настроек уведомлений.
