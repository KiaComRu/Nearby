# Nearby для ПК 0.5.7 — сверка с веб/PWA 0.5.6

Последняя опубликованная ПК-сборка до этого выпуска — 0.5.4. Веб/PWA обновлялась отдельно; её исходники и установщики ПК используют разные номера версий.

| Изменение | ПК 0.5.4 | ПК 0.5.7 |
|---|---|---|
| Таблицы: файл, размер, дата/время, статус, открыть, удалить | Карточки | Перенесено в обе таблицы |
| Открытие оригинала и полученного файла | Скачивание/папка | Через Windows, с привязкой к выбранному или принятому файлу |
| Выбор устройств между «Подключением» и «Передачей» | Только в отправке из Проводника | Отдельная вкладка при двух и более подключениях |
| Обычная отправка выбранному получателю | Файл доступен всем подключённым клиентам | Строго одному выбранному подключению |
| Одновременный приём от входящих клиентов и от другого ПК | Интерфейс переключался целиком на другой ПК | Оба канала обслуживаются независимо от выбора получателя |
| Потеря получателя | Возможность общей публикации | Очередь останавливается, новый получатель выбирается явно |
| Счётчик на «Передаче» | Отображался | Только на «Подключении» |
| Мобильный локальный клиент | Соседние панели | Отправка и получение друг под другом, прокрутка таблиц |
| Вход по QR/ссылке локального ПК | Лишнее нажатие | Автоматически; подтверждение включается в дополнительных настройках |
| Выбор способа подключения | На основном экране | В дополнительных настройках |
| Переход к интернет-версии | Принудительный режим «интернет» | Актуальная веб-версия сама выбирает транспорт |

Локальный PIN ПК остаётся шестизначным: он уже короче девятизначного веб-ID и относится к другому протоколу. Девятизначные ID, автоматический WebRTC/HTTPS-выбор и восстановление через шифрованный серверный канал доступны в актуальной веб-версии, которую открывает кнопка приложения. PWA, установка на телефон и языки сайта относятся к веб-интерфейсу; локальное окно Windows остаётся русскоязычным. Приложение поддерживает несколько входящих клиентов и одно исходящее подключение к другому ПК одновременно; для дополнительного ПК откройте приглашение этого компьютера на нём.

Удаление строки скрывает историю, не удаляя сохранённые файлы. Доступ к локальному открытию требует ключ владельца на loopback; произвольный путь из запроса не принимается. Открытие оригинала в оболочке использует путь реально выбранного файла; загруженные файлы связываются с завершённой загрузкой WebView2. Параметры сообщений и пути от удалённого устройства не используются как команды Windows.

Оба установщика собираются заново: Windows 10/11 x64 и Windows Server 2016 x64 Desktop Experience. Server 2016 компилируется против .NET Framework 4.6.2. Проверка на физическом Server 2016 отдельно не выполнялась.

Проверки: `npm test`, `node scripts/desktop-parity-e2e.mjs`, `node scripts/desktop-parity-native-e2e.mjs`, сценарии PC/TLS/discovery/Explorer, `node scripts/update-native-e2e.mjs`, `node scripts/update-installer-e2e.mjs`. Проверяется изоляция адресата, бинарные и пустые файлы, реальный WinForms/WebView2, открытие оригинала/принятого файла и сохранность файлов после удаления строки. Нативный тест не запускает пользовательские приложения: обработчик открытия заменён журналом пути.
