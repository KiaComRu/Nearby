# Nearby 0.5.8 — превью файлов и подсказки статуса

Изменения включены в веб/PWA и в установщик: Windows 10/11 x64.

Слева от названия отправленного или полученного изображения появляется миниатюра. Поддерживаются PNG, JPEG, GIF, WebP, AVIF и BMP, которые декодирует браузер/WebView2. Для остальных форматов, повреждённых изображений и изображений больше 8 МиБ остаётся значок с расширением. Миниатюра создаётся на устройстве, до 96 пикселей по длинной стороне; исходный файл не изменяется. Превью не является отдельной передачей и не увеличивает статистику.

В столбце «Статус» виден только значок ⓘ. Наведение, фокус клавиатуры или нажатие открывают текстовую подсказку. Повторное нажатие, Escape или нажатие вне значка закрывают её. Текст обновляется вместе со статусом. Полоса прогресса расположена под названием файла. На телефоне таблица прокручивается горизонтально.

В Windows доступны превью выбранных оригиналов, принятых сервером файлов и загрузок, сохранённых WebView2. API проверяет доступ к конкретной записи, а мост Windows читает только зарегистрированные приложением файлы; произвольные пути не принимаются. HTML и SVG не открываются как миниатюры. Чтение изображения ограничено 8 МиБ, временные blob-ссылки освобождаются после уменьшения; удаление записи освобождает её миниатюру и сохраняет файл на диске.

Проверки: `npm test`, `node scripts/internet-e2e.mjs`, `node scripts/desktop-parity-e2e.mjs`, `node scripts/desktop-parity-native-e2e.mjs`, `node scripts/browser-e2e.mjs`, `node scripts/web-i18n-e2e.mjs`, `node scripts/pwa-e2e.mjs`. Проверяется настоящая передача PNG/WebP, получение на диск, подсказки мышью, касанием и клавиатурой, смена статуса, права доступа и запрет активных форматов.
