# Поэтапные улучшения Nearby

Основание: [исследование LocalSend, PairDrop и AirDash](UPSTREAM-REVIEW.md). Ограничение владельца: пока без новых платных услуг.

| Этап | Содержание | Состояние |
|---|---|---|
| 1 | Устройства рядом, выбор ПК, проверка адреса и диагностика | Реализован в 0.4.0; см. DISCOVERY.md |
| 2 | Защищённый локальный транспорт, проверяемое первое сопряжение, «Мои устройства», отзыв доверия | Реализован в 0.5.0 для установленных ПК; см. TRUSTED-DEVICES.md |
| 3 | Окно частей вместо ожидания каждой части, скорость/ETA и общий прогресс набора | Следующий этап; нужны проверки задержек, памяти и отмены |
| 4 | Автоматический выбор прямого WebRTC/TURN/зашифрованного HTTPS | Часть с TURN отложена: новая платная инфраструктура не согласована; нынешний HTTPS-режим сохраняется |
| 5 | PWA, Wake Lock, ссылки/текст и Share | PWA реализован; см. PWA.md. Wake Lock, ссылки/текст и Share остаются отдельными задачами |
| 6 | Большие файлы, докачка, папки, возможный адаптер LocalSend | Отдельный последующий этап; нельзя заменить повышением лимитов |

Этапы выпускаются отдельно, чтобы проверять транспорт и совместимость перед следующим изменением. Автопоиск не равен постоянному сопряжению или шифрованию. Для каждого этапа нужны автоматические проверки и испытания физических устройств. Код третьих проектов не включается в Nearby без проверки лицензий.
