# Nearby для Windows 0.6.6 — работа в системном трее

Нажатие кнопки сворачивания скрывает окно Nearby в системный трей. Приложение остаётся запущенным: встроенный движок и WebView2 не закрываются, текущие сопряжения сохраняются, отправка и приём продолжаются в фоне.

Нажмите значок Nearby в трее, чтобы вернуть окно. Правой кнопкой доступно меню:

- **Открыть Nearby** — вернуть окно в прежнее обычное или развёрнутое состояние.
- **Проверить обновления** — открыть окно и выполнить проверку.
- **Выход** — завершить Nearby, остановить движок и удалить значок из трея.

Обычная кнопка закрытия окна также завершает приложение. Для фоновой работы используйте сворачивание. Повторный запуск Nearby и команда «Отправить через Nearby» из Проводника возвращают прежнее окно, сохраняя движок и подключения. Выбранные в Проводнике файлы появляются в выборе получателя.

Уведомления об обновлениях используют тот же значок. Кнопка «Позже» скрывает предложение обновления, сохраняя значок и фоновую работу. Для установки обновления по-прежнему нужно завершить текущие передачи.

Обновление доступно для Windows 10/11 x64. Достаточно установить новую версию поверх прежней; файлы и сохранённые сопряжения остаются на месте. Веб/PWA сохраняет версию 0.6.4.

## Проверка фоновой работы

`scripts/tray-native-e2e.mjs` использует настоящее окно WinForms/WebView2 и отдельные браузерные устройства. Проверяются сворачивание во время прямой отправки, работа интернет-сеанса в скрытом окне, отправка и приём с SHA-256 после шести минут простоя, возврат через меню, восстановление развёрнутого окна, открытие из Проводника и остановка движка через «Выход».

На время простоя отладчик WebView2 отключается. Прямое WebRTC-соединение перед этим завершается: оно не должно маскировать проблемы интернет-сеанса с фоновыми таймерами. Системный сон и завершение сеанса Windows в этой проверке не моделируются.
