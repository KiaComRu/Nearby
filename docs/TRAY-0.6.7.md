# Nearby для Windows 0.6.7 — восстановление окна из трея

Окно возвращается по одному или двойному щелчку по значку Nearby, через пункт «Открыть Nearby» и повторный запуск приложения. Восстановление защищено от повторного скрытия при изменении состояния окна; окно выводится на передний план. Обычный и развёрнутый размеры сохраняются. Движок и подключения продолжают работать.

Поддерживаемая сборка для ПК — Windows 10/11 x64 с .NET Framework 4.8 и WebView2. На сайте одна кнопка скачивания, обновление использует один канал `windows-build.json`. Старый серверный профиль, его установщики, канал обновления и инструкция удалены из публичных загрузок. Полученные файлы и сопряжения существующих установок не меняются.

Проверено настоящее окно WinForms/WebView2: сообщения значка трея для щелчка и двойного щелчка, пять повторных восстановлений, пункт меню, прежний движок, развёрнутое окно и открытие из Проводника. На прежнем коде 0.6.6 уведомление двойного щелчка оставляло окно свёрнутым. В 0.6.7 проверка проходит.

Передача с SHA-256 продолжается во время сворачивания. После шести минут простоя с отключённым DevTools сохранены интернет-сеанс и передача в обе стороны. Системный сон и выход из пользовательского сеанса не проверялись.
