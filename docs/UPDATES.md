# Обновления Nearby для Windows

Начиная с 0.5.4 приложение проверяет новую версию после запуска, затем каждые шесть часов, пока окно работает. Внизу окна есть «Проверить обновления». Без интернета автоматическая проверка не мешает работе локальной передачи и не открывает сообщения об ошибке.

Когда доступна новая версия, появляется уведомление Windows и полоса в приложении с кнопками «Обновить» и «Позже». «Позже» скрывает предложение до следующей проверки или запуска. Ручная проверка снова покажет доступное обновление.

«Обновить» скачивает установщик с HTTPS-сайта Nearby в локальный кеш приложения. Проверяются продукт, профиль Windows, номер версии, имя установщика, размер при наличии его в метаданных и SHA-256. Перенаправления загрузки не разрешены. Файл с неверной суммой не запускается; частичная загрузка удаляется. Перед запуском проверка повторяется. Равная или более старая версия не предлагается.

Если идёт передача, установка откладывается: скачанный пакет остаётся готовым, а кнопка меняется на «Установить». Нужно дождаться окончания передачи и закрыть окно отправки из Проводника. Перед завершением приложение блокирует новые локальные действия, а движок атомарно проверяет текущие передачи и прекращает принимать новые операции. Если запуск установщика не удался, движок возобновляет работу.

Установщик ждёт завершения запросившего его процесса до 30 секунд, не завершает другие экземпляры принудительно, заменяет файлы программы в пользовательской установке и автоматически запускает Nearby. Права администратора не нужны. Настройки, сохранённые сопряжения, WebView2 и полученные файлы находятся вне каталога программы и не удаляются.

Для обычной Windows используется `https://nearby.kiacom.ru/downloads/windows-build.json`, для сборки Server 2016 — `windows-server-2016-build.json`. Обновление выбирает свой профиль автоматически. Метаданные публикуются после установщиков и содержат `product`, `version`, `platform`, `installer`, `sha256`, `size`. Публикация следующего выпуска с новым номером в этом же канале запускает предложение обновления у существующих клиентов.

Установленные 0.5.3 и более ранние версии ещё не содержат проверку обновлений. Актуальную 0.6.6 нужно один раз установить обычным установщиком поверх прежней. Версии 0.5.4 и новее получают предложение обновления автоматически. Удалять прежнюю программу не требуется; последующие обновления предлагаются внутри приложения.

Тестовые сборки пока не имеют цифровой подписи издателя. SHA-256 проверяется по метаданным доверенного HTTPS-сайта; это не отдельная цифровая подпись выпуска. Защита зависит от сохранности сайта и компьютера.

Проверки: `npm test`, `node scripts/update-native-e2e.mjs`, `node scripts/update-installer-e2e.mjs`. Проверяются настоящее окно WinForms/WebView2, предложение обновления, скачивание и передача управления установщику, отклонение повреждённых пакетов, отмена, профили Windows, запрет отката, ожидание загрузок и приёма, а также настоящий NSIS-установщик в изолированной временной папке. Тест установщика не изменяет реестр, ярлыки или установленную пользователем программу. Сборка Server 2016 компилируется против .NET Framework 4.6.2; физический Server 2016 отдельно не проверялся.
