# Проверки Nearby

## 12 октября 2026 — браузерный режим WebRTC

- Все 24 теста прошли локально на Windows/Node.js 24.13.0, включая PHP-сигналинг на PHP 8.5.11. На Sweb проверен синтаксис API PHP 8.3.
- Проверены одноразовое приглашение, роли, обязательное подтверждение устройства, недоступность комнаты с чужим ключом, лимит JSON и отказ до подтверждения.
- Проверены SHA-256 частей, точность двоичных и пустых файлов, отказ, повреждение данных, отмена посреди передачи с сохранением соединения и разрыв.
- Chromium: два изолированных контекста, передача в обе стороны, сохранение через Blob/download, отсутствие ошибок JavaScript и горизонтального переполнения при 390 px.
- Потоковая запись проверяется настоящим FileSystemWritableFileStream в OPFS через тестовую замену выбора файла. Системный диалог `showSaveFilePicker` автоматически не проверялся.
- Проверки выполняются локально и через HTTPS на Sweb. Физические телефоны, разные компьютеры/роутеры и файлы 100 МиБ/10 ГиБ пока не проверены. Windows-установщик не пересобирался.

## 12 октября 2026 — подготовка исходников к GitHub

- `npm test`: все 17 тестов прошли на Windows, Node.js 24.13.0.
- `node --check public/app.js` и `node --check desktop/windows/host.mjs`: успешно.
- Передача и завершение дочернего движка проверяются на loopback с временными папками.
- Проверка содержимого ранее собранного Windows-дистрибутива выполнена. В чистом клоне без dist этот тест явно пропускается.
- Публикуемый комплект содержит исходники и тестовые фикстуры, без полученных пользовательских файлов, node_modules, средств сборки, готового установщика и лендинга.

## Пределы проверки

Полный цикл установки/работы окна/удаления на чистой Windows не выполнен. Браузерный сценарий и адаптивная вёрстка проверялись на одном компьютере. Это не подтверждает работу с физическим iPhone/Android, правилами брандмауэра или производительность сети. macOS-сборки и проверки Catalina отсутствуют. Публичный аудит безопасности не проводился.
